How it works

Traditional Langton's Ant uses the rule LR. On one cell state the ant turns left; on the other it turns right. After turning, the current cell changes state and the ant moves forward. Repeating these tiny local rules produces surprisingly complicated behaviour.

Longer rules such as LLRR or LRRL introduce additional cell states. Each state receives its own colour and corresponding turning instruction.
